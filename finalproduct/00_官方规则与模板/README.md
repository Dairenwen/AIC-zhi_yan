## 提交格式（以报名系统最终页面为准）

| 材料 | 强制格式或限制 |
| --- | --- |
| 作品名称 | 不超过 20 字 |
| 作品简介 | 不超过 300 字，按“问题-方案-效果-应用”组织 |
| 作品方案 | 按算法创新赛模板完成，PDF，10 MB 以内 |
| 演示视频 | MP4，3 至 5 分钟，300 MB 以内 |
| 答辩 PPT | 覆盖背景、核心技术、创新点、应用前景，提交 PDF |
| 佐证材料 | 合并为一个 PDF，证明真实性、创新性或应用成效 |
| 其他材料链接 | 百度网盘永久有效链接；根目录和文件都按团队编号、赛题、作品名称、材料名称命名 |

## 重要合规要求

- 评审材料中不得出现学校名称、学校 Logo、指导教师或其他可识别团队身份的信息。
- 作品必须原创、数据与案例真实可靠，并具备合法的知识产权和数据授权。
- 湖北赛区当前公开安排：校赛于 2026-10-10 前完成；报名及缴费于 2026-10-15 20:00 前截止；省赛于 2026-10-31 前完成。
